# Ayan Shakeel — Portfolio

A one-page portfolio featuring experience, skills, and eight Python projects.

## Edit

Open `index.html` in a text editor. Project cards and links are in the `#projects` section; colours and spacing are in the `<style>` block near the top. Commit and push changes to `main` to update the GitHub Pages site.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.
